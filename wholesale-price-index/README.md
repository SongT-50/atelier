# 도매 가격지수 (Wholesale Price Index)

한국 농산물 **도매 단계** 가격을 32개 품목 고정 바스켓으로 묶은 단일 지수.
**2018년 = 100** 기준, **2018-01 ~ 2026-08 · 105개월** 시계열.

```
2025년 (마지막 완전연도)   144.4      기준 대비 +44.4%
2026년 1~8월 (진행 중)     136.8      전년 같은 기간 대비 -6.7%
```

---

## 어떻게 계산했나

표준 **라스파이레스 지수**입니다.

```
지수_t  =  Σ(p_t · q₀) / Σ(p₀ · q₀) × 100
```

- `p` = 품목별 평균 단가(원/kg, **물량가중**)
- `q₀` = **기준기간 물량으로 고정** — 가중치가 매기 바뀌지 않으므로 가격 변동이 이중 반영되지 않습니다
- 바스켓 = 기준기간에 단가와 물량이 모두 있는 품목 (32개)

연간 지수는 기준연도를, 월간 지수는 기준월을 100으로 둡니다.

---

## ⚠️ 이 지수가 **아닌** 것

읽기 전에 이 절을 먼저 보십시오. 아래를 모르고 쓰면 틀린 결론이 나옵니다.

1. **전체 도매 거래가 아닙니다.** 주요 32품목의 공통 바스켓이고, 전체의 **부분집합**입니다.
2. **소비자 물가가 아닙니다.** 도매 단계 값이고, 유통 마진·소매 단계가 들어 있지 않습니다.
3. **기준연도가 하나입니다.** 2018 고정이라 기간이 길어질수록 바스켓이 현재 소비 구조에서 멀어집니다.
   (5년 단위 재기준은 다음 판의 과제입니다.)
4. **월간 지수는 계절조정을 하지 않았습니다.** 전월 대비보다 **전년 동월 대비**로 보십시오.
5. **진행 중인 해는 완전한 해와 직접 비교할 수 없습니다.**
   상반기는 계절 요인 때문에 연간값보다 구조적으로 높게 나옵니다(완전연도 대비 **+8~12%** 관측).
   ⇒ 진행 중인 해는 **전년 같은 기간과** 비교하십시오.

### 아직 재지 않은 것

- **다른 지수와의 비교** — 국내에 도매 단계 지수를 상시 내는 곳이 있는지 **조사하지 않았습니다.**
  *"이런 게 없다"* 고 말할 근거가 우리에게 없습니다.
- **품목 선정이 결과에 얼마나 민감한가** — 바스켓을 바꿨을 때 지수가 얼마나 움직이는지 안 쟀습니다.
- **이 지수를 누가 필요로 하는가** — 수요를 측정한 적이 없습니다.

## 데이터

`data/price_index.json`

| 키 | 내용 |
|---|---|
| `headline` | 마지막 완전연도 · 진행 중 연도 · 전년 동기 대비 |
| `annual` | 연간 지수 시계열 (`index`, `n_products`, `change_pct`, `is_partial`) |
| `monthly` | 월간 지수 시계열 |
| `contributors` | **기여도 분해** — 어느 품목이 지수를 몇 포인트 밀어올렸/내렸나 |
| `caveats` | 위 「아닌 것」의 기계 판독본 |

`contributors` 가 이 데이터의 특징입니다. 지수가 올랐다는 사실만이 아니라
**무엇이 얼마나 올렸는지** 포인트 단위로 분해되어 있습니다
(예: 2025년 +44.4pt 중 사과 단독 +10.47pt).

---

## 검증

- 회귀 시험 **8/8** 통과
- 지수 산식을 **손계산으로 독립 대조** — 코드가 낸 값과 일치
- `contributors` 의 기여도 합이 헤드라인 변동폭과 일치하는지 자동 확인 (`sum_check_pt`)

⚠️ **검증된 것과 안 된 것을 구별해 주십시오.** 위 셋은 *"산식이 스스로와 맞는가"* 를 확인한 것이지
*"이 지수가 시장을 잘 대표하는가"* 를 확인한 것이 아닙니다. 뒤엣것은 안 쟀습니다.

## 출처와 이용

원자료는 **공공 API로 공개된 도매시장 거래 자료**입니다.
해당 데이터셋의 이용허락범위는 원 제공처 표기 기준 **제한 없음**입니다.

> ⚠️ 원 제공처의 표기를 그대로 옮긴 것이며, 이용 조건은 **직접 확인하시기 바랍니다.**
> 저희가 확인한 시점 이후에 바뀌었을 수 있습니다.

가공물(이 지수와 코드)은 자유롭게 쓰셔도 됩니다. 틀린 곳을 찾으시면 알려주십시오.
