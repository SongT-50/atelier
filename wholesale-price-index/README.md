# 도매 가격지수 (Wholesale Price Index)

한국 농산물 **도매 단계** 가격을 고정 바스켓으로 묶은 단일 지수.

| | 기간 | 점 수 | 바스켓 | 기준 |
|---|---|---|---|---|
| **연간** | 2018 ~ 2026 | 9개년 | 32품목 | **2018년 = 100** |
| **월간** | 2024-01 ~ 2026-08 | 32개월 | **31품목** | **2024-01 = 100** |

⚠️ **연간과 월간은 기준도 바스켓도 다릅니다.** 두 값을 같은 자로 잰 것처럼 나란히 놓지 마십시오.

```
2025년 (마지막 완전연도)   144.4      기준 대비 +44.4%
2026년 1~8월 (진행 중)     136.8      전년 같은 기간 대비 -6.7%
```

---

## 어떻게 계산했나

표준 **라스파이레스 지수**입니다.

```
지수_t  =  Σ(p_t · q₀) / Σ(p₀ · q₀) × 100
```

- `p` = 품목별 평균 단가(원/kg, **물량가중**)
- `q₀` = **기준기간 물량으로 고정** — 가중치가 매기 바뀌지 않으므로 가격 변동이 이중 반영되지 않습니다
- 바스켓 = 기준기간에 단가와 물량이 **모두** 있는 품목만

바스켓 크기가 연간 32 · 월간 31로 다른 것은 이 조건 때문입니다. 기준기간이 다르면
(연간은 2018년, 월간은 2024-01) 조건을 만족하는 품목 집합도 달라집니다.
**숫자를 외우지 말고** 산출물의 `basket_size` · `monthly_basket_size` 를 읽으십시오.

## ⚠️ 이 지수가 **아닌** 것

읽기 전에 이 절을 먼저 보십시오. 아래를 모르고 쓰면 틀린 결론이 나옵니다.

1. ### **전수가 아니라 표본입니다.**
   원자료 전부를 집계한 것이 아니라 **월별 최대 7일**을 뽑아 계산했습니다 — 총 **728일**.
   따라서 **표본 오차가 있습니다.** 그 크기는 **재지 않았습니다.**
   *"전수 정산"* 이나 *"표본 오차 없음"* 으로 읽지 마십시오. 수집이 전수인 것과
   모집단을 대표하는 것은 다른 문제입니다.
2. **전체 도매 거래가 아닙니다.** 주요 32품목의 공통 바스켓이고, 전체의 **부분집합**입니다.
3. **소비자 물가가 아닙니다.** 도매 단계 값이고, 유통 마진·소매 단계가 들어 있지 않습니다.
4. **기준연도가 하나입니다.** 2018 고정이라 기간이 길어질수록 바스켓이 현재 소비 구조에서 멀어집니다.
   (5년 단위 재기준은 다음 판의 과제입니다.)
5. **월간 지수는 계절조정을 하지 않았습니다.** 전월 대비보다 **전년 동월 대비**로 보십시오.
6. **월간은 연간의 부분이 아닙니다.** 기준월이 **2024-01 = 100** 이고 바스켓도 **31품목**이라,
   월간 지수값을 연간 지수값과 직접 비교할 수 없습니다.
7. **진행 중인 해는 완전한 해와 직접 비교할 수 없습니다.**
   상반기는 계절 요인 때문에 연간값보다 구조적으로 높게 나옵니다(완전연도 대비 **+8~12%** 관측).
   ⇒ 진행 중인 해는 **전년 같은 기간과** 비교하십시오.

### 아직 재지 않은 것

- **표본 오차의 크기** — 월 7일 표본이 그 달 전체를 얼마나 잘 대표하는지 **재지 않았습니다.**
  7일을 다르게 골랐을 때 지수가 얼마나 흔들리는지도 안 봤습니다.
- **다른 지수와의 비교** — 국내에 도매 단계 지수를 상시 내는 곳이 있는지 **조사하지 않았습니다.**
  *"이런 게 없다"* 고 말할 근거가 우리에게 없습니다.
- **품목 선정이 결과에 얼마나 민감한가** — 바스켓을 바꿨을 때 지수가 얼마나 움직이는지 안 쟀습니다.
- **이 지수를 누가 필요로 하는가** — 수요를 측정한 적이 없습니다.

## 무엇이 들어 있나

```
generate_price_index.py        지수를 만드는 코드
test_generate_price_index.py   회귀 시험 8건
data/price_trend.json          입력 — 품목별 연간/월간 평균단가·물량 (32품목)
data/price_index.json          산출 — 지수
```

```bash
python generate_price_index.py        # 입력에서 지수를 다시 만든다
python generate_price_index.py --json # 파일을 안 건드리고 stdout 미리보기
python test_generate_price_index.py   # 회귀 시험 8건
```

### 산출 `data/price_index.json`

| 키 | 내용 |
|---|---|
| `headline` | 마지막 완전연도 · 진행 중 연도 · 전년 동기 대비 |
| `annual` | 연간 지수 시계열 (`index`, `n_products`, `change_pct`, `is_partial`) |
| `monthly` | 월간 지수 시계열 |
| `contributors` | **기여도 분해** — 어느 품목이 지수를 몇 포인트 밀어올렸/내렸나 |
| `caveats` | 위 「아닌 것」의 기계 판독본 |

`contributors` 가 이 데이터의 특징입니다. 지수가 올랐다는 사실만이 아니라
**무엇이 얼마나 올렸는지** 포인트 단위로 분해되어 있습니다
(예: 2025년 +44.4pt 중 사과 단독 +10.47pt).

## 검증

- 회귀 시험 **8/8** 통과 — **직접 돌려 보십시오**: `python test_generate_price_index.py`
- 지수 산식을 손계산과 대조 — 2품목·2기간을 손으로 푼 값과 코드 값이 일치
  (`test_laspeyres_pure_function`, 시험 파일 안에 계산 과정이 적혀 있습니다)
  ### ⚠️ 이 대조는 **독립적이지 않습니다.** 지수를 만든 쪽이 함께 만든 시험이고,
  손계산도 그 시험 파일 안에 있습니다. **만들지 않은 사람이 검산한 적은 없습니다.**
  ⇒ 그래서 이건 *"산식이 스스로와 맞는다"* 의 근거일 뿐입니다.
  **당신이 손으로 검산해 주시면 그게 첫 독립 대조가 됩니다.**
- `contributors` 의 기여도 합이 헤드라인 변동폭과 일치하는지 자동 확인 (`sum_check_pt`)
- **재현 대조** — 입력에서 다시 계산한 결과가 발행된 `price_index.json` 과
  `generated`(생성 시각)만 빼고 **완전히 일치**함을 확인했습니다.

⚠️ **검증된 것과 안 된 것을 구별해 주십시오.** 위는 *"산식이 스스로와 맞는가"* 를 확인한 것이지
*"이 지수가 시장을 잘 대표하는가"* 를 확인한 것이 아닙니다. 뒤엣것은 안 쟀습니다.
시험 8건 중 **7건은 `data/price_trend.json` 을 읽습니다** — 입력이 바뀌면 결과도 바뀝니다.

## 출처와 이용

원자료는 **공공 API로 공개된 도매시장 거래 자료**입니다(공공데이터포털 데이터셋 `15141809`).
해당 데이터셋의 이용허락범위는 원 제공처 표기 기준 **제한 없음**입니다.

> ⚠️ 원 제공처의 표기를 그대로 옮긴 것이며, 이용 조건은 **직접 확인하시기 바랍니다.**
> 저희가 확인한 시점 이후에 바뀌었을 수 있습니다.

가공물(이 지수와 코드)은 자유롭게 쓰셔도 됩니다. 틀린 곳을 찾으시면 알려주십시오.

## 저희가 답을 모르는 것들

*"틀린 곳을 찾으면 알려주십시오"* 라고만 적는 것은 저희가 이미 여러 번 해봤고
**한 번도 답이 오지 않은** 방식입니다. 그래서 **구체적으로** 묻겠습니다.
아래는 저희가 답을 모르는 질문이고, **하나만 답해 주셔도 값집니다.**
[Issues](../../issues)에 한 줄이면 됩니다.

1. ### **월 7일 표본으로 충분합니까?**
   같은 달에서 **다른 7일**을 골랐을 때 지수가 얼마나 움직이는지 저희는 안 쟀습니다.
   재보셨다면, 혹은 *"그 정도면 무의미하다/치명적이다"* 판단이 서신다면 알려주십시오.

2. ### **이미 이런 지수를 내는 곳이 있습니까?**
   저희는 **조사하지 않았습니다.** 있는데 저희가 모르는 것일 수 있습니다.
   있다면 그쪽 값과 이 값이 **다릅니까?** 다르면 어느 쪽이 이상합니까?

3. ### **바스켓 32품목이 당신 분야에서 말이 됩니까?**
   빠지면 안 될 품목이 빠져 있습니까? 반대로 들어가면 안 될 것이 들어 있습니까?

4. ### **2018 고정 기준이 지금 해석을 망칩니까?**
   8년이 지나 소비 구조가 바뀌었을 텐데, 그게 실제로 얼마나 문제인지 저희는 모릅니다.

5. ### **`contributors` 분해가 당신이 아는 시장 사건과 맞습니까?**
   어느 품목이 지수를 몇 포인트 밀어올렸는지 나와 있습니다.
   현장에서 겪으신 것과 **어긋나는 항목**이 있으면 그게 가장 값진 제보입니다.

6. ### **이 데이터가 당신에게 쓸모가 있습니까? 없으면 왜 없습니까?**
   *"필요 없다"* 도 답입니다. 저희는 **수요를 측정한 적이 없습니다.**
